# Getting started

## Before you open chat

An administrator must install Nautobot Agent, configure a default Agent model, and grant the appropriate Nautobot permissions. You do not need to edit deployment configuration as an ordinary user. Read [Privacy and data handling](privacy.md) before sending requests; messages and relevant data go to the configured model provider, and traces are enabled by default.

## Start your first chat

1. Open **Nautobot Agent → Agent**.
2. If the composer is disabled, a default Agent model has not been configured. Ask your administrator to finish setup, then reload the page.
3. Enter a Nautobot-related question in the message composer and press **Enter** to send. Use **Shift+Enter** to insert a line break.
4. Follow the run status and review the response. It may include text or a visualization. Built-in inventory tools are read-only and limited by your Nautobot permissions.

For administrator setup, see [Installation](../admin/install.md) and [Configuration](../admin/configuration.md). For saved history, see [Conversations](conversations.md).
